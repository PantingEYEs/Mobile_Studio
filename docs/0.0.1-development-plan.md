# Mobile Studio 0.0.1 研发规划与技术路线图

> 本文档为 0.0.1 阶段的功能规划与技术方案参考，明确技术边界与核心实现路径，不代表最终发布成果。

## 一、阶段定位与核心目标

在 Android 15 + One UI 7.0 宿主（Knox 0x0 / 无 Root）环境下，基于 Termux (Go 后端) + Svelte (前端 UI) + Shizuku，构建一个能在本地独立运行、开箱即用、全权限开放的轻量级 DevStudio 原型。

---

## 二、0.0.1 核心功能规划与实现方案

### 1. 项目生命周期管理
- **项目模板与脚手架**：
  - 提供 Android (Kotlin/Java)、Go、Web 空白模板快速初始化。
  - **多 Android API 级别储备**：预备并支持多版本 Android SDK Platform（覆盖 API 31 ~ API 35 / Android 12~15），支持在新建项目时自选 `compileSdk`、`targetSdk` 与 `minSdk`，并支持必要 SDK 平台的按需配置。
  - **环境适配自动注入**：初始化 Android 项目时，自动在 `gradle.properties` 注入 aarch64 架构专用的 `aapt2FromMavenOverride`。
- **JDK 版本管理**：内置支持 OpenJDK 17（主流推荐）与 OpenJDK 21 切换，预留自定义 `JAVA_HOME` 环境变量配置入口。
- **项目导入导出与删除**：
  - 导入：支持从系统存储目录解压导入或通过 Git Clone 远程拉取。
  - 导出：支持一键打包为 `.zip` 导出至系统公共 Download 目录。
  - 删除：提供二次确认的文件系统级清理。

### 2. 代码导航与版本控制
- **轻量文件树浏览**：
  - 仅展示文件与目录树状结构，不内置复杂行级代码编辑器。
  - 支持一键快捷复制文件绝对路径/相对路径，便于配合外部终端操作。
- **Git 分支与拓扑视图**：
  - 基于本地 `git` 指令解析 Commit、Branch 与 Tag 信息。
  - 前端以可视化折线或紧凑列表展示 Git 拓扑历史，严格遵循非快进（No Fast-Forward）合并展示。

### 3. 全开放 Web 控制台 (Terminal Bridge)
- **极简无鉴权直连**：
  - 面向开发者全权开放，去除 Token 鉴权流程，前端直接通过 WebSocket 连接本地 PTY，开箱即用。
- **全功能伪终端 (PTY)**：
  - 后端基于 Go PTY 桥接 Termux 的 bash 进程。
  - 前端基于 xterm.js 实现流式输出与输入交互，支持完整快捷键与 ANSI 颜色渲染。

### 4. 构建与包管理
- **编译与签名**：
  - 核心支持标准 `.apk` 增量编译与自动 debug.keystore 自签名。
  - 支持编译生成用于上架分发的 `.aab`（.aab 作为成果归档导出，不支持本机直接安装运行）。
- **编译性能保障**：
  - 首次构建前检测并提供通过 Shizuku 放宽 Android 15 幻影进程限制（Phantom Process Killer）的指令。

### 5. Shizuku / ADB 调试与运行
- **静默安装与卸载**：通过 Shizuku (`rish`) 调用 `pm install -r` 实现免确认一键热安装。
- **运行控制与监控**：
  - 支持快速拉起应用主 Activity (`am start`) 或强制停止 (`am force-stop`)。
  - 提供实时 `logcat` 日志流捕获面板，支持按应用 Package Name / Tag 过滤，替代复杂的断点调试器。

---

## 三、关键功能边界与暂不实现项

1. **暂不实现 IDE 级断点单步调试器 (Debugger)**：0.0.1 阶段以实时 Logcat 与进程控制代替 JDWP 挂载。
2. **暂不实现本地 AAB 直接运行**：因系统原生不支持 AAB 安装，暂不引入复杂的 `bundletool` 转码管道。
3. **暂不实现内置复杂代码编辑器**：鼓励用户使用 Acode、Neovim 等专业编辑器编写业务逻辑。
